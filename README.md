# RescueWavy

### Turning surplus food into someone's next meal.

RescueWavy is a real-time food rescue platform that connects surplus food donors with shelters and volunteers through one coordinated workflow.

The platform helps manage the complete journey:

**Donor → Smart Match → Shelter → Volunteer → Delivery**

---

## Problem

Surplus food can be generated by events, cafeterias, restaurants and other food-serving organizations.

At the same time, shelters and community organizations may need food but lack a simple way to discover and coordinate available surplus.

The challenge is not only finding surplus food, but coordinating:

- What food is available?
- How much is available?
- Which shelter can accept it?
- Where is the shelter?
- Who will collect it?
- Has the food actually been delivered?

---

## Solution

RescueWavy provides a centralized workflow for food rescue.

A donor can create a food donation with its description, category, quantity, expiry time and location.

The system then identifies a suitable shelter using matching criteria such as:

- Food compatibility
- Shelter capacity
- Distance
- Urgency

After a shelter confirms the rescue, a volunteer pickup workflow is created.

The donation progresses through:

**Available → Matched → Pickup Assigned → Picked Up → Delivered**

---

## Key Features

### Food Donation

Donors can register surplus food with:

- Food description
- Food category
- Quantity
- Expiry time
- Location

### AI-Assisted Food Classification

RescueWavy can process natural-language food descriptions and help identify the appropriate food category.

For example:

> 10 kg cooked rice with dal

can be classified as:

**Cooked**

The AI is used as an assistance layer while the core rescue workflow remains deterministic and explainable.

### Smart Shelter Matching

The matching system considers:

- Food compatibility
- Shelter capacity
- Distance
- Urgency

### Shelter Dashboard

Shelters can:

- View rescue requests
- Review available food
- Confirm a rescue
- Reject a request

### Volunteer Pickup

Volunteers can:

- View available pickups
- Accept a pickup
- Mark food as picked up
- Mark food as delivered

### Impact Dashboard

The dashboard tracks:

- Delivered food
- Completed deliveries
- Active pickups
- Food categories
- Rescue pipeline
- Estimated meals
